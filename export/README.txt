RADIO SILENCE
=============

Steal the other teams' keys, crack their bunker puzzles, rob the vaults and bank the loot.
Up to 4 teams, 2 or 4 players per team, AI fills empty slots. 8 maps (or "Random map").

HOW TO START
  Windows : run "Radio Silence.exe".
            SmartScreen may say "Windows protected your PC" (the exe is not code-signed):
            click "More info" -> "Run anyway".
  Linux   : run "./Radio Silence.x86_64"  (if it won't start: chmod +x "Radio Silence.x86_64")
  macOS   : unzip, move "Radio Silence.app" to Applications, then RIGHT-CLICK -> Open the first time
            (the app is not notarized). If macOS says it is damaged, run in Terminal:
            xattr -cr "/Applications/Radio Silence.app"

LAN / HAMACHI
  Host: HOST LAN GAME. Others: JOIN LAN GAME - games on your network (and Hamachi) show up automatically.
  Allow the game through the firewall when asked (UDP ports 7777 and 7778).

CONTROLS (keyboard + mouse)
  WASD move / drive     Mouse look & aim     LMB fire     RMB aim down sights (vehicle: MG)
  SHIFT sprint   C/CTRL crouch   SPACE jump   R reload   1/2/3 or wheel: weapons
  G grenade / medkit   E use / enter vehicle / hold at puzzle terminals / man the mortar
  F switch vehicle seat   TAB scores   ESC pause & options

Settings are saved in your user folder; the first start takes a moment while vehicle graphics are baked.
